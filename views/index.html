    端口

    选 443 时 GitHub 写 ssh.github.com:443，选 22 时写标准 github.com:22。 与"有没有开代理"无关：OpenSSH 不读 HTTP_PROXY，该不该用 443 取决于你的网络是否封 22。 这里的初始值取自该平台**现有配置**，没配置过才默认 443。
